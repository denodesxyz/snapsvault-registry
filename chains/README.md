# Chains

Contributor files live at `chains/<network>/<chain ID>/<contributor>.json`. The network folder sets the name and logo shown in the Marketplace. The chain ID folder sets the chain ID and whether it is a mainnet or a testnet. Each file lists one contributor for one chain ID.

The rules are in [Registry file](https://docs.snapsvault.xyz/contributing/registry-file) and [Feed format](https://docs.snapsvault.xyz/contributing/feed-format) in the docs. [CONTRIBUTING.md](../CONTRIBUTING.md) explains the check that runs on every pull request.
