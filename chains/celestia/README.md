# Celestia

Contributor files for the Celestia network, one folder per chain ID:

| Folder | Chain ID | Chain |
|---|---|---|
| `celestia/` | `celestia` | Mainnet |
| `mocha-4/` | `mocha-4` | Testnet |
| `mocha-5/` | `mocha-5` | Testnet |

A contributor with snapshots for several chain IDs adds one file to each folder, with the same file name and the same `contributor` object, for example `celestia/deNodes.json` and `mocha-5/deNodes.json`.
